## Run (XAMPP)
1. Copy this folder to `/Applications/XAMPP/xamppfiles/htdocs/student-result-management/`
2. Start Apache + MySQL in XAMPP.
3. Open http://localhost/phpmyadmin → Import → `database/student_result_management.sql`
4. Open http://localhost/student-result-management/
5. Login: `admin` / `admin123` (password is hashed automatically on first run)

DB credentials are in `database.php` (default XAMPP: root, empty password).
Bootstrap, Bootstrap Icons, Chart.js and Google Fonts load from free CDNs.
